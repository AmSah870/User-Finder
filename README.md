Описание программы

User-Finder — это GUI-приложение на Python для профессионального поиска разработчиков и специалистов непосредственно в базе данных **GitHub**. Используя официальный GitHub API, программа позволяет находить таланты по всему миру, фильтровать их по технологическому стеку, геолокации и популярности.

Основные возможности:
- ✅ Глобальный поиск: Поиск по логину, полному имени или ключевым словам в био.
- ✅ Гео-фильтрация: Поиск разработчиков в конкретных городах или странах (например, `Moscow`, `Germany`).
- ✅ Стек технологий: Фильтрация по основному языку программирования (Python, JS, Rust и др.).
- ✅ Метрики популярности: Поиск по количеству подписчиков (`followers`) и публичных репозиториев.
- ✅ Прямые ссылки: Мгновенный переход в профиль пользователя на GitHub прямо из приложения.
- ✅ Экспорт лидов: Сохранение найденных профилей (ссылки, имена, локации) в форматы JSON или CSV.

Инструкция по запуску

Требования:
- Python 3.8 или выше
- Установленная библиотека `requests` для работы с API
- [Опционально] GitHub Personal Access Token (для обхода лимитов анонимных запросов)
